First public release of Clipora: a desktop app that downloads one public video at a time from **Instagram Reels, TikTok and YouTube** and saves it as MP4 on your computer.

> **Early release.** The installers are **not signed** yet, so macOS and Windows show a warning the first time you open the app. See [how to open it](https://github.com/felipebweber/clipora#download-and-install). The Windows build passes all automated checks but has not been tested by hand on a real Windows PC yet. Please [open an issue](https://github.com/felipebweber/clipora/issues) if something doesn't work.

## Download

| System | File |
|---|---|
| macOS (Apple Silicon and Intel, macOS 11+) | `Clipora_0.1.0_universal.dmg` |
| macOS (Apple Silicon only, smaller) | `Clipora_0.1.0_aarch64.dmg` |
| Windows 10/11 x64 | `Clipora_0.1.0_x64-setup.exe` (or `Clipora_0.1.0_x64_en-US.msi`) |
| Windows 11 ARM | `Clipora_0.1.0_arm64-setup.exe` |
| Debian, Ubuntu, Linux Mint, Pop!_OS | `Clipora_0.1.0_amd64.deb` / `Clipora_0.1.0_arm64.deb` |
| Fedora, openSUSE, RHEL-based | `Clipora-0.1.0-1.x86_64.rpm` / `Clipora-0.1.0-1.aarch64.rpm` |
| Arch Linux and derivatives | AUR package `clipora-bin` (coming soon) |

Verify downloads with `SHA256SUMS-<platform>.txt`. Each installer also has a GitHub build provenance attestation: `gh attestation verify <file> -R felipebweber/clipora`.

## What it does

- Paste a link, preview the video and pick the quality (YouTube shows only the resolutions each video offers).
- MP4 with AAC audio, preferring H.264 so it plays in most players.
- Download progress and cancel; local history of completed downloads.
- Everything runs on your computer; nothing is sent anywhere by Clipora.

Not supported: YouTube Shorts, live streams, Stories, private videos, videos that require login and playlists.
